Events are fetched for the visible period: from a URL or with a function. `loading` reports the start and the end of it.

<Example client:only="svelte" slug="event-sources" />

## Code

<Tabs syncKey="framework">
<TabItem label="Vanilla JS">

```js
import {createCalendar, TimeGrid} from '@event-calendar/core';
import '@event-calendar/core/index.css';

const events = [/* your events */];

const ec = createCalendar(document.getElementById('ec'), [TimeGrid], {
    view: 'timeGridWeek',
    scrollTime: '08:00',
    eventSources: [{
        // Here could be a request to your server for the period from info.start to info.end
        events: info => new Promise(resolve => setTimeout(() => resolve(events), 700))
    }],
    loading: isLoading => console.log('loading', isLoading)
});
```
