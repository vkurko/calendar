The same events shown in the time of New York. Any IANA time zone name works, as well as `UTC` and `local`.

<Example client:only="svelte" slug="time-zone" />

## Code

<Tabs syncKey="framework">
<TabItem label="Vanilla JS">

```js
import {createCalendar, TimeGrid} from '@event-calendar/core';
import '@event-calendar/core/index.css';

const events = [/* your events */];

const ec = createCalendar(document.getElementById('ec'), [TimeGrid], {
    view: 'timeGridWeek',
    timeZone: 'America/New_York',
    nowIndicator: true,
    // A moment in time is an ISO string with an offset
    events: events.filter(event => !event.allDay).map(event => ({
        ...event,
        start: event.start.toISOString(),
        end: event.end.toISOString()
    }))
});
```

</TabItem>
