The events that happen at the same time placed side by side, with `slotEventOverlap: false`. By default they overlap a little to save space.

<Example client:only="svelte" slug="no-overlap" />

## Code

<Tabs syncKey="framework">
<TabItem label="Vanilla JS">

```js
import {createCalendar, TimeGrid} from '@event-calendar/core';
import '@event-calendar/core/index.css';

const today = new Date();
const events = [/* your events */];

const ec = createCalendar(document.getElementById('ec'), [TimeGrid], {
    view: 'timeGridDay',
    slotEventOverlap: false,
    scrollTime: '08:00',
    // All the events of the week on the same day
    events: events.filter(event => !event.allDay).map(event => ({
        ...event,
        start: new Date(today.getFullYear(), today.getMonth(), today.getDate(), event.start.getHours(), event.start.getMinutes()),
        end: new Date(today.getFullYear(), today.getMonth(), today.getDate(), event.end.getHours(), event.end.getMinutes())
    }))
});
```
