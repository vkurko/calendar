A view of your own is a standard view with other options: here, four days instead of a week.

<Example client:only="svelte" slug="custom-view" />

## Code

<Tabs syncKey="framework">
<TabItem label="Vanilla JS">

```js
import {createCalendar, TimeGrid} from '@event-calendar/core';
import '@event-calendar/core/index.css';

const today = new Date();
const events = [/* your events */];

const ec = createCalendar(document.getElementById('ec'), [TimeGrid], {
    view: 'timeGridFourDay',
    views: {
        timeGridFourDay: {
            type: 'timeGridWeek',
            duration: {days: 4}
        }
    },
    // The text of the button of the new view
    buttonText: text => ({...text, today: 'Today', timeGridFourDay: '4 days', timeGridWeek: 'Week'}),
    headerToolbar: {start: 'title', center: '', end: 'timeGridFourDay,timeGridWeek today prev,next'},
    scrollTime: '08:00',
    events
});
```
