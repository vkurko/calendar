Drag the bottom edge of an event to change its duration — or the top edge, with `eventResizableFromStart`.

<Example client:only="svelte" slug="resize" />

## Code

<Tabs syncKey="framework">
<TabItem label="Vanilla JS">

```js
import {createCalendar, TimeGrid, Interaction} from '@event-calendar/core';
import '@event-calendar/core/index.css';

const events = [/* your events */];

const ec = createCalendar(document.getElementById('ec'), [TimeGrid, Interaction], {
    view: 'timeGridWeek',
    editable: true,
    eventStartEditable: false,
    eventResizableFromStart: true,
    scrollTime: '08:00',
    events,
    eventResize: ({event}) => {
        console.log('eventResize', event.title, event.start, '–', event.end);
    }
});
```
