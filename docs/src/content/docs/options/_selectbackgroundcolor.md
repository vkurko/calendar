- Type `string`
- Default `undefined`
- Requires `Interaction` plugin

The background color of the selection, see [selectable](../selectable/).

The value is any CSS color, such as `'#f00'`, `'rgb(255,0,0)'` or `'red'`:

```js
let options = {
    selectable: true,
    selectBackgroundColor: '#93c5fd'
};
```
