## Example

<Tabs syncKey="framework">
<TabItem label="Vanilla JS">

```js
let options = {
    dayCellContent: ({date}) => ({
        html: `<b>${date.getDate()}</b> <small>${date.toLocaleDateString('en', {weekday: 'short'})}</small>`
    })
};
```

</TabItem>
<TabItem label="Svelte">

```svelte

    {/snippet}
</Calendar>
```

</TabItem>
